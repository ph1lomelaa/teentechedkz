# Portfolio UP: прошедшие активности

[Инструкция в PDF](Portfolio-UP-guide.pdf) · [Редактируемая презентация](Portfolio-UP-guide.pptx)

Ссылка организатора необязательна. Для прошлого опыта нужны название, тип, период и результат. Ссылка, организатор, роль и файл необязательны. Ментор подтверждает результат или возвращает на правки. Изменение записи снова отправляет её на проверку.

Прошлый опыт хранится в портфолио конкретного ученика, не публикуется в общем каталоге и не создаёт текущих задач или дедлайнов. Для текущих и будущих активностей сохраняется процесс через каталог.

## Запуск

Применить миграцию `135` командой `alembic upgrade head` перед запуском обновлённого backend.

Тестовый стенд: `docker compose -f docker-compose.portfolio.yml up -d --build`. Интерфейс: `VITE_LOCAL_API_PORT=8017 npm run dev --prefix frontend -- --host 127.0.0.1 --port 3017`.

Скриншоты в презентации сделаны на синтетических данных тестового стенда.
