# Редактирование шаблонов roadmap

В разделе `/roadmap-templates` выберите «Редактировать». Редактор сохраняет настройки,
этапы, задачи и подзадачи одним запросом `PUT /api/v1/roadmap-templates/{id}`.
Сроки задаются в днях после назначения; пустое значение означает отсутствие срока.
Порядок элементов задаётся кнопками вверх/вниз.

Сохранение меняет только шаблон. Уже назначенные студентам roadmap остаются
самостоятельными копиями. Все поля задач и подзадач, включая идентификаторы Notion
и ссылки на анкеты вида `/p/...`, сохраняются.

Каждый запрос содержит `revision` из полученного шаблона. При устаревшей версии API
отвечает `409`, не меняя данные. Редактор предлагает загрузить текущую версию после
подтверждения потери своего черновика. Сервер блокирует строку шаблона на время
сохранения; импорт использует ту же блокировку.

После ручного сохранения устанавливается `locally_edited=true`. Повторный импорт
Notion пропускает такой шаблон целиком с результатом `skipped_local_edits`, в том
числе не добавляет новые задачи из него в существующие roadmap студентов. Импорт
остальных шаблонов сохраняет прежнее поведение. Возврат к управлению шаблоном из
Notion через интерфейс не предусмотрен.

Несохранённые правки вызывают предупреждение при переходе через интерфейс и
закрытии/обновлении вкладки. Черновик дополнительно хранится в `sessionStorage`,
чтобы восстановить его при повторном открытии редактора в той же вкладке, в том
числе после перехода через историю браузера. Подтверждённый выход без сохранения
через интерфейс удаляет черновик. При недоступном хранилище остаются предупреждения.

## Развёртывание

Перед запуском обновлённого приложения применить миграцию `125`:

```sh
cd backend
alembic upgrade head
```

Миграция добавляет `locally_edited` и `revision` в `roadmap_templates`. Старые записи
получают значения `false` и `1`. Ранее сделанные локальные правки автоматически
определить нельзя; шаблоны, которые нужно защитить, следует сохранить через редактор.

## Проверки

```sh
.venv/bin/python -m pytest backend/tests/test_roadmap_template_editing.py backend/tests/test_roadmap_subtask_deadlines.py backend/tests/test_roadmap_notion_local_edits.py -q
cd frontend
npm test -- src/components/roadmap/TemplateEditor.test.tsx
npm run build
```

Дополнительная проверка реального PostgreSQL находится в
`backend/tests/test_roadmap_template_postgres.py`. Она запускается только при
`TTE_ROADMAP_TEST_DATABASE_URL`, указывающем на отдельную временную БД с префиксом
`tte_roadmap_test_`; рабочую БД использовать нельзя.
